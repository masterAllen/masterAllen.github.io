装机记三：杂项设置

本地编辑 | 打开本地目录 | 复制路径

软件遇到的问题: Ranger, Thunar, Feh...

Ranger 配置

1. ranger 退出时能够留在当前目录

touch $HOME/.rangerdir
.zshrc --> alias ranger='ranger --choosedir=$HOME/.rangerdir; LASTDIR=`cat $HOME/.rangerdir`; cd "$LASTDIR"'

Thunar 自动挂载 U 盘 / 显示 Windows 盘

- Wiki 最重要，多看，基本步骤就是按照这个来的
- 首先把(thunar)设置为(dameon)进程，我直接在(i3)中加了(thunar --dameon)
- 需要安装的包：gvfs
- 按照(Wiki)的步骤，一步一步来
--- 启动(thunar)
--- edit->preference->advanced->enable volume
--- edit->preference->click configure
------- mount removable drives
------- mount removable media

Feh 配置文件更改

1. 修改按键

- 先查阅(Arch Wiki)，上面说了可以(configure)，然后给了链接，是(MAN)手册里面
- 那就查阅(MAN)手册好了，按照步骤进行即可(配置文件：.config/feh/keys, 键位命令通过 man 查找)
- 刚开始配置无效，在网上查阅一份样本，照葫芦画瓢就行
- 最后设置成和(zathura)一致的快捷键，具体看装机记二最后的配置文件

2. 命令行输入某图片名称，只能看这个图片，看不了其他图片

https://wiki.archlinux.org/index.php/Feh
Archwiki 已经给出解决方法了，把这个脚本放到你喜欢的位置就行

3. 调整大小之后，切换另外图片然后在切换回来，之前调整的大小就失效了

原来命令行有这样的选项(--keep-zoom-vp)
