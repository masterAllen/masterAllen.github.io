装机记二：常用软件安装

本地编辑 | 打开本地目录 | 复制路径

安装后要做的事情...

Pacman 设置

vim etc/pacman.conf

[archlinuxcn]
Server = https://repo.archlinuxcn.org/$arch

基本安装

# 图形基本支持包
sudo pacman -S xorg
# git
sudo pacman -S git
# i3wm
sudo pacman -S i3
# gvim(arch的基本 vim 不支持 clipboard)
sudo pacman -S gvim
# gnome-terminal
sudo pacman -S gnome-terminal
# picom(桌面美化)
sudo pacman -S picom 
# 触摸板
sudo pacman -S libinput
# zsh
sudo pacman -S zsh
# scort(截图软件)
sudo pacman -S scort
# feh(图片查看)
sudo pacman -S feh
# polybar
sudo pacman -S polybar alsa
# firefox
sudo pacman -S firefox
# NetworkManager
sudo pacman -S networkmanager
# Sougou
sudo pacman -S fcitx fcitx-configtool
sudo pacman -S fcitx-gtk2 fcitx-gtk3 fcitx-qt4 fcitx-qt5
sudo pacman -S fcitx-sogoupinyin
# pip3(pip，pip3 都包含了)
sudo pacman -S python-pip
# lightdm(登录界面)
sudo pacman -S lightdm lightdm-webkit2-greeter
# BaiduNetdisk
sudo pacman -S baidunetdisk-bin

手动设置

  • polybar

    # 安装相关字体(从配置文件搜索font)
yay -S siji ttf-unifont

  • feh

    # 设置壁纸
feh --bg-scale background_path

  • 搜狗拼音

    fcitx-configtool
InputMethod -> 添加Sogou
Global Config -> 设置快捷键

# 注意点
出了问题可以卸载重新安装

  • gnome-terminal

    # 配色
Edit->Preference->Color->Solarized
# Scrolling
Edit->Preference->Scrolling->show scrollbar
# Text
Source Code Pro Regular 19
# 顶端栏(menu bar)
关闭: Edit->Preference->General->Show Menubar
打开: 在终端空白的地方右击，显示menubar，然后和关闭一样操作

  • oh-my-zsh

    cd $HOME/.oh-my-zsh/plugins
git clone https://github.com/zsh-users/zsh-syntax-highlighting
git clone https://github.com/zsh-users/zsh-autosuggestions

  • 字体设置

    YaHei.ttf --> /usr/share/fonts/
sudo mkfontscale
sudo mkfontdir
sudo fc-cache –fv

  • 百度云

    cd /usr/share/applications
vim baidunetdisk.desktop

在Exec的一行添加--force-device-scale-factor=2.0，意思为扩大两倍。
例如更改后为Exec=/usr/lib/baidunetdisk/baidunetdisk --no-sandbox --force-device-scale-factor=2.0 %U

登录界面

# /etc/lightdm/lightdm.conf
# [Seat:*] 下面
greeter-session=lightdm-webkit2-greeter
# /usr/share/lightdm-webkit/
git clone 相应主题(推荐litarvan)
# litarvan 直接有 aur 包，安装就行
pacman -S lightdm-webkit-theme-litarvan

# /etc/lightdm
修改 lightdm-webkit2-greeter.conf : theme

配置表

Program File path
vim $HOME/.vimrc
polybar $HOME/.config/polybar
picom $HOME/.config/picom.conf
i3 $HOME/.config/i3/config
keyboard $HOME/.Xmodmap
touchpad /etc/X11/xorg.conf.d/70-synaptics.conf
zsh $HOME/.zshrc
v2sub /usr/lib/python3.8/site-packages/v2sub
