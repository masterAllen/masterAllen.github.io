Windows 软件点击关闭按钮隐藏到托盘

本地编辑 | 打开本地目录 | 复制路径

来自十天后的更新

直接让 AI 大人帮忙用 AutoHotKey 去实现即可（我是用的 Grok Bot）。五分钟，向 AI 大人投降，对软件行业是毁灭性打击！！

我有一个需求，我希望 cursor 打开我的笔记工程后，可以一直在后台运行，而不是关闭。因为 cursor 每次打开速度太慢太慢了。但是这就有一个关键点：我经常会习惯性点击右上角关闭按钮，让我养成点击最小化按钮的习惯有点难。

所以，现在的需求就是：能否在 cursor 点击关闭按钮后，隐藏到托盘，而不是关闭。 类似于微信等软件一样。

其实也有人在官方论坛中提过这样的需求，但是还没有被实现。而且考虑到，我希望的是只是对于打开笔记工程会关闭，打开其他的工程还是照旧，这种需求应该比较小众，所以只好自己实现。

在 GPT 的协助下，完美解决！解决方案：使用 4t Tray Minimizer 的 6.05 beta 版本（必须要这个版本）。

Some tips about 4t Tray Minimizer

  1. 让 GPT 帮忙下载 beta 版本，我自己在官网上居然没找到。

  2. 点击收藏夹下面的新建按钮，然后就会弹出一个新建窗口，这个时候打开 cursor 窗口，点击识别就能识别到了。

  3. 可以一路确定，到了标题栏那里，设置如下。要注意一定要选择关闭按钮，我之前不小心弄成了最小化按钮，结果试了半天发现不行，最后才发现选错了... 此外，还可以把鼠标点击那里弄成右键点击，这样可以很方便先试一下行不行。

  4. 最后一路确定就行。如果像我这种，只想要打开笔记工程才会隐藏到托盘，可以在识别那里选择窗口标题，然后填入正确的正则表达式即可。

原理

下面是我比较好奇其中的原理，然后问了 GPT，他的回答如下：

核心原理是：识别你对窗口按钮的操作，按规则隐藏窗口，再用托盘图标提供恢复入口。Cursor 进程继续运行。

具体涉及三部分：

  1. 监听鼠标和窗口事件。
    Windows 提供“钩子”机制，让程序监听鼠标事件或窗口消息。我检查了你电脑上的 4t 程序和 Tray.dll，确实发现它们引用了 SetWindowsHookEx 等钩子接口。不过，仅凭这些引用，还不能确定它对 Cursor 使用了哪一种钩子。微软钩子文档

  2. 判断你点击的是哪个按钮。
    标准 Windows 窗口能通过“命中测试”报告鼠标位于关闭、最小化还是标题栏区域。例如，HTCLOSE 表示关闭按钮。自定义标题栏的事件处理可能不同，需要额外适配。微软命中测试文档

  3. 隐藏窗口并管理托盘图标。
    Windows 分别提供隐藏/恢复窗口、添加/删除托盘图标的接口。“收到托盘”通常就是把这些功能组合起来，应用仍占用内存，后台任务也可以继续运行。窗口显示接口、托盘图标接口
